01项目简介

WeakRadar 是一个「复习教练」：粘贴一段课程笔记或错题，系统把它切成知识点卡片； 复习时卡片正面只给知识点，翻面才看到原句；你给自己打 0–5 分，系统按 SM-2 间隔重复 排出这张卡的下一次到期时间。

它特别的地方是没有自己的数据库。每张卡的调度状态（due / ease / interval / reps）和每次自评日志，都是一条 PowerContext 记忆条目； 「今天该复习什么」是把记忆列出来解析出来的，「我上次卡在哪」是向记忆搜索出来的。

02解决的真实痛点

大二计科学生的资料并不缺，缺的是「知道自己哪里不会」并且「不会丢」。

不知道哪些是真不会

数据结构、计组、概率论三科笔记散在纸质本、Notion、微信群和 PPT 里。复习时只能从头看， 时间大量花在已经掌握的内容上。

→ 只推到期的卡片，而且翻面前不给答案，避免「看着答案觉得会」。

卡过的点，第二天就忘了自己卡过

上周明明卡在「红黑树 case2 / case3 的旋转判断」，这周打开资料，已经想不起自己当时卡在哪， 于是同一处反复卡。

→ 低分自评作为记忆条目留下痕迹，可随时用关键词把它召回。

换个设备 / 会话，进度全丢

复习进度通常绑在某个 App 或某个本地文件里。换电脑、重装环境、换一个助手，等于从零开始。

→ 进度存在 PowerContext 的记忆作用域里，任何客户端读同一个 Scope 就能接上。

03核心功能

01

笔记切卡片

粘贴一段笔记，按编号 / 分号 / 句号 / 行首 - 要点 切成知识点卡片， 重复内容自动跳过——重复粘贴不会生成第二张卡。

02

今日复习（SM-2）

按 SM-2 算出的 due 挑出到期卡片。正面只有知识点，翻面才见原句， 复习前先装配一段「今日上下文」。

03

0–5 六档自评

「完全没印象 → 轻松掌握」六档。评分更新 ease / interval / reps 并回写卡片，同时追加一条复习日志。

04

记忆召回与核对

关键词召回历史薄弱点，返回 score 与 matched_by； 记忆原文面板直接展示 memory 条目，评审核对「记忆是否真的在用」。

04技术结合：PowerContext 记忆读写如何起作用

调度状态的唯一事实来源是 PowerContext Memory。所有上游调用集中在 server/powercontext_client.py，不引入额外数据库。

写自评结果如何进入记忆

  1. 建工作区：每个科目一个 Scope，幂等键 weakradar-<科目>，重复点击不会建出两个。
  2. 记卡片：导入笔记后，每条知识点以 kind=review_card 写成一行结构化文本。
  3. 改记忆：自评后用上游返回的完整 citation 走 entries/revise 改写卡片文本，版本号推进——不是新增一张卡。
  4. 留日志：每次自评再追加一条 kind=review_log，历史低分点永久留在记忆里。

读记忆如何变成今天的复习

  1. 算今日：entries/list 列出该 Scope 全部条目，本地按 card| 前缀解析出到期卡片。
  2. 装配上下文：复习前调用 /v1/context/prepare，页面展示装配结果与条目引用。
  3. 召回薄弱点：/v1/memory/search 关键词命中「卡住 / 旋转 / 到期」这类词，把历史薄弱点挠回来。
  4. 可核对：/api/memory/raw 原样返回记忆条目；每张卡显示自己的 mem_ent_… 条目号，自评后 due/ease/reps 的变化在卡片与记忆原文里同时可见。
调用的 PowerContext 接口
环节接口作用
建工作区POST /v1/scopes每个科目一个 Scope，幂等键 weakradar-<科目>
记卡片POST /v1/memory/rememberkind=review_card，写入卡片文本
算今日POST /v1/memory/entries/list列出全部条目，本地解析出到期卡片
自评回写POST /v1/memory/entries/revise按 citation 改卡片文本，版本推进
复习日志POST /v1/memory/rememberkind=review_log，追加一条评分记录
记忆召回POST /v1/memory/search关键词召回薄弱点，返回 score / matched_by
上下文装配POST /v1/context/prepare复习前装配上下文，证明记忆被复用

存进记忆里的卡片长这样

card|subject=数据结构|topic=红黑树插入|due=2026-11-16|ease=2.5|interval=3|reps=2|last=4|note=<原句摘要>

一行文本既是卡片内容，也是调度状态。due 为 ISO 日期，ease 为 SM-2 难度因子（1.3–2.8）， interval 为天数，last 为上次评分。因此「记忆」不是装饰：删掉记忆，今日清单就空了。

06运行三步

1

启动 PowerContext 服务

使用赛事官方开源的 PowerContext（Apache-2.0），本项目未修改其源码。默认监听 127.0.0.1:8000。

powercontext server

2

启动应用

上游地址读环境变量，不硬编码：POWERCONTEXT_SERVER_URL，默认 http://127.0.0.1:8000。仓库根目录执行：

uv run --with fastapi --with uvicorn \
  --with httpx --with pydantic python -m server.app

3

打开页面

访问 http://127.0.0.1:8080， 选科目建 Scope → 粘贴笔记切卡片 → 今日复习里翻面自评。顶部的绿色圆点表示与 PowerContext 连通。

http://127.0.0.1:8080

依赖 Python 3.12+，只用 uv run --with … 启动，不额外建 venv。后端 9 条路由， GET /api/health 可查看 PowerContext 就绪状态与当前 Scope。
